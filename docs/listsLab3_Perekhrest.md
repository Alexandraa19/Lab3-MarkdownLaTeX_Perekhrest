# Списки в Markdown

## Маркированные списки

Создаются с помощью символов `-`, `*` или `+`:

- Пункт 1
- Пункт 2
- Пункт 3

## Нумерованные списки

Создаются с помощью цифр с точкой:

1. Первый пункт
2. Второй пункт
3. Третий пункт

## Вложенные списки

используйте отступ (таб или 4 пробела):

1. Пункт
   - Подпункт
   - Подпункт

##  Подготовка структуры

### Задачи на сегодня

1. Изучить систему контроля версий
   - Git базовые команды
   - Работа с ветками
   - Устаревший подход Современный workflow

2. Освоить разметку документации
   - Markdown синтаксис
   - Форматирование текста
   - Создание таблиц и списков

3. Изучить основы программирования
   - JavaScript синтаксис
   - Работа с DOM
   - Асинхронные операции

1. Создать папку проекта со следующей структурой:
   - Файл README.md для описания проекта
   - Папка src/ для хранения исходного кода
   - Папка docs/ для документации
   - Файл .gitignore для исключения ненужных файлов

2. Инициализировать Git-репозиторий

```bash
git init
```

3. Настройка репозитория

```bash
git add .
git status
git commit -m "Initial commit: базовая структура проекта"
```

##  Работа с удалённым репозиторием

4. Настройка удаленного репозитория

```bash
git remote add origin <url>
git push -u origin main
```
